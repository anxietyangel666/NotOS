# Роли и участники: реализовано

## Roles

- Список ролей в настройках группы.
- Поиск ролей по названию.
- Сортировка ролей: по порядку, по имени, по количеству участников.
- Создание новой роли.
- Удаление роли.
- Копирование ID роли.
- Счетчик участников у каждой роли с учетом всех ролей пользователя.
- Группировка ролей по категориям кастомизации.
- Сворачивание и разворачивание категорий ролей.
- Настройка роли по умолчанию для новых участников группы.
- Редактор роли с отдельными вкладками:
  - Display;
  - Permissions;
  - Members.
- Display:
  - изменение названия роли;
  - изменение цвета роли;
  - настройка отображения участников с ролью отдельно.
- Permissions:
  - поиск по правам;
  - включение и выключение прав роли;
  - поддержанные права: ManageRoles, DeleteAnyMessage, ManageChannels, ManageInvites, KickMembers;
  - empty state, если по поиску прав ничего не найдено.
- Members внутри редактора роли:
  - список участников, у которых есть эта роль;
  - поиск участников внутри роли;
  - снятие роли с участника;
  - список участников, которым можно выдать роль;
  - выдача текущей роли участнику прямо из редактора роли.
- Save/Reset bar для несохраненных изменений роли.
- Права текущего пользователя считаются по всем его ролям, а не только по основной роли.
- Серверная проверка прав тоже агрегирует permissions по всем ролям участника.

## Members

- Табличный список участников.
- Поиск участников.
- Сортировка участников:
  - по дате присоединения к группе;
  - по дате создания аккаунта;
  - по алфавиту.
- Фильтр участников по роли.
- Колонки:
  - Name;
  - Member Since;
  - Joined Discord;
  - Roles.
- Отображение ролей участника:
  - показывается первая роль;
  - остальные роли сворачиваются в +N;
  - по +N открывается выпадающий список всех ролей участника.
- Добавление роли участнику через кнопку +.
- Удаление отдельной роли у участника.
- Кик участника при наличии права KickMembers.
- Выбор участников чекбоксами.
- Select all для текущего отфильтрованного списка.
- Массовое добавление роли выбранным участникам.
- Массовое снятие роли с выбранных участников.
- Очистка выбранных участников.
- При изменении ролей сервер рассылает всем клиентам группы обновленный список участников.

## Backend и данные

- Участник может иметь несколько ролей.
- Основная роль хранится в group_members.role_id.
- Дополнительные роли хранятся в group_member_roles.
- listGroupMembers возвращает roleIds: основная роль + дополнительные роли.
- API обновления роли участника поддерживает:
  - roleId;
  - addRoleId;
  - removeRoleId.
- При добавлении новой роли старая основная роль не теряется: она сохраняется как дополнительная.
- Owner-role нельзя выдать или снять через обычное управление ролями.

## UX/UI

- Вкладки настроек, список ролей и список участников увеличены и выровнены.
- Строки ролей сделаны крупнее и ровнее.
- Редактор роли организован по вкладкам вместо одного длинного блока.
- Список участников адаптирован под узкое окно.
- Выпадающие меню ролей и bulk actions стилизованы в одном стиле с настройками.
